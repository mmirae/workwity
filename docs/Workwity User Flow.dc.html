C-02 AI 핵심
공고 등록 · AI 자동 태깅 검수
행동 기존 공고 링크 또는 줄글 붙여넣기 → AI가 뽑은 전형 태그를 한 화면에서 수정/확정 → [발행] AI OpenAI 파싱: 채용 전형 태그(코테·과제·면접 횟수), 직무·경력, 성향 벡터 보정값, 항목별 신뢰도 점수 추출. 신뢰도 낮은 태그는 노란 배지로 표시해 사람이 반드시 보게 함 다음 → 저신뢰 시 A-01 검수 큐 / 정상 시 C-03
→
C-03 MVP
지원자 리스트
행동 공고별 지원자를 Match% 순으로 훑어보기 시스템 지원 시점에 스냅샷된 Match%와 유형 코드를 함께 노출. 정렬만 제공하고 자동 필터링(탈락)은 하지 않음 — 평가 도구가 아니기 때문 다음 → C-04 지원자 상세
→
C-04 MVP
지원자 상세 · 상태 변경
행동 지원자 Work-TI 리포트 + 이력 확인 → [검토중 / 합격 / 불합격] 상태 변경 시스템 상태 업데이트 후 구직자에게 이메일 알림. 메시지 기능 없이 상태값만으로 루프를 닫는다 다음 → C-03 복귀
검증 포인트 — AI 태그의 사람 수정률. 수정률이 30%를 넘으면 프롬프트/태그 사전 문제이며, 이 수치가 콜드 스타트 전략 전체의 생존 지표다.
