채용 플랫폼 만들기 · 제품 기획 워크시트

- 팀 이름: Workwity (워크위티)
- 날짜: 2026년 7월 16일

💡 최종 정리 (Executive Summary)
누구를 (1번 고객): 불필요하고 획일적인 채용 전형에 지친 Z세대 주니어 구직자 & 가치관 불일치로 조기 퇴사를 겪는 초기 스타트업 인사담당자

어떤 가치로 (2번): "나에게 딱 맞는 회사 찾기, Work with Identity"라는 목표 아래, 구직자가 선호하는 채용 전형을 직접 필터링하고, 업무 성향(Work-TI) 매칭을 통해 조기 퇴사율과 채용 번아웃을 방지하는 가치

어떤 기능으로 (3번): 24문항(16개 유형) 기반 업무 성향 테스트 + 3문항의 조직 언어 문화 테스트, 선호/기피 채용 전형 검색 필터, OpenAI API 기반 비정형 채용 공고 자동 정형화 및 스코어링 파이프라인

문제 정의: 기존 채용 플랫폼은 구직자가 공고를 일일이 읽기 전에는 채용 전형(코테 유무, 면접 횟수 등)을 알 수 없으며, 기업의 '실제 일하는 방식'을 사전에 검증할 수 없어 양측 모두에게 번아웃과 조기 퇴사 비용을 초래한다.

핵심 가치: 1. 구직자에게는 선호 채용 전형(예: 코테 없음, 1차 면접만) 맞춤 검색 기능 제공.
2. 기업에게는 구직자가 선호하는 채용 전형 데이터를 바탕으로 채용 문화를 개선하고, Work Identity Match 기반 매칭으로 조기 퇴사를 방지.

핵심 기능: 4대 대립 축(16가지 유형) 및 소통 취향 배지 도출 테스트, 선호 채용 전형 커스텀 검색 필터, Supabase 기반의 쿼리 매칭 엔진

첫 사용 시나리오: 구직자가 랜딩 페이지 접속 후 3~5분 만에 24개의 업무 성향 테스트와 3개의 보너스 질문(소통 방식)을 완료 ➔ AI가 분석한 'WORK-TI REPORT' 카드 확인 ➔ 대시보드 검색창에서 [✓ 코딩테스트 없음], [✓ 1차 면접] 필터 선택 ➔ 나와 Work Identity Match 92% 등 수치가 높고 원하는 채용 전형을 가진 공고 확인 후 익숙한 [지원하기] 버튼 클릭.

가격 가설: 초기 트래픽 확보를 위해 구직자 전면 무료, 기업 무료 매칭. 향후 정식 서비스 전환 시 매칭 성공 수수료 5% 책정 및 기업 브랜딩 유료 솔루션 판매.

1. 기회 선택 · 포지셔닝맵의 빈칸 하나로
우리가 고른 기회 영역: 스타트업 타깃의 '선호 채용 전형 맞춤형 X 양방향 Work Identity 매칭' 블루오션

그 장벽을 넘을 우리 팀의 강점:

"신입은 변별 데이터가 적다"는 한계를 '업무 성향(Work-TI)'과 '선호하는 채용 전형'이라는 능동적 데이터로 돌파.

구직자들이 어떤 채용 전형에 몰리는지 데이터를 축적하여, 기업이 긍정적인 방향으로 채용 문화를 개선하도록 유도(시장 혁신 가설).

콜드 스타트 문제는 OpenAI API를 활용한 '비정형 공고의 성향/채용 전형 태그 자동 추출 파이프라인'으로 우아하게 해결.

2. 문제 정의 · 한 사람의 고통으로
핵심 고객: 1~3년 차 주니어 개발자/마케터/디자이너 등 Z세대 구직자

상황: 획일적인 AI 면접이나 무의미한 코딩테스트에 피로감을 느끼며, 본인의 일하는 스타일(Identity)을 존중받을 수 있는 곳을 찾고 싶음.

장애물: 기존 대형 플랫폼(사람인, 원티드 등)은 공고의 줄글을 다 읽어보지 않으면 이 회사가 코테를 보는지, 과제를 주는지, 임원 면접이 있는지 알 길이 없음.

그래서 겪는 고통: 나에게 맞지도 않는 채용 전형을 준비하느라 심각한 취업 번아웃을 겪고 구직 효율이 극단적으로 떨어짐.

문제 정의 한 문장: 기존 채용 플랫폼은 '구직자가 선호하는 채용 전형'을 조건으로 검색할 수 있는 필터가 없어 심각한 채용 번아웃을 유발하며, 기업 역시 비효율적인 채용 전형을 고집하다 좋은 인재를 놓치고 있다.

3. 가치가설 · 무엇으로 돈이 되나
우리가 주는 핵심 가치:

구직자: 기피 채용 전형 차단(필터링)을 통한 심리적 해방감 및 구직 리소스 극적 절감. 재미있는 성향 테스트 기반의 공감.

기업: 조기 퇴사 방지 및 구직자들의 채용 전형 선호도 데이터를 바탕으로 한 '효율적인 채용 프로세스' 개선 인사이트 획득.

수익 모델: 매칭 성공 시 합리적인 수수료(5%) 및 기업 브랜딩 유료 솔루션.

4. 핵심 기능 = 그 가치를 주는 최소 수단
우리가 주는 핵심 가치: 구직자가 원하는 채용 전형으로 회사를 찾게 하고, 업무 성향(Identity)을 매칭해 준다.

이 가치를 주려면 / 사용자가 이걸 한다 / 그래서 이 기능이 필요

구직자 성향 규격화 및 재미 유발 / 3~5분간 24개+3개의 딜레마 질문 응답 / Work-TI 테스트 및 개인 WORK-TI REPORT 생성 기능

원하는 채용 방식 서칭 / 첫 화면에서 원하는 채용 전형 필터를 체크 / 공고 데이터 필터링 검색 엔진 (e.g., 코딩테스트 유무, 면접 횟수 등)

공고 자동화 / 기업이 줄글 공고 링크를 넣음 / OpenAI API 연동 비정형 공고의 태그(채용 전형, 성향) 추출 스크립트

지금은 버릴 기능: 커피챗 등 특수 전형 강제 프로세스(일반적인 '지원하기'로 통일), 복잡한 추천 알고리즘 모델 직접 개발(단순 SQL 쿼리로 대체).

우리만의 핵심 기능 1개: 채용 전형(태그) 커스텀 검색 필터 + Supabase DB 절댓값 거리를 활용한 Work Identity Match 정렬 매칭 엔진.

5. 첫 사용 흐름 작성 (User Flow)
화면 1: 랜딩 및 업무 성향 온보딩

가치: 진입 장벽을 낮추는 감성 카피로 유저를 유입시키고, 3분 테스트를 통해 본인의 일하는 스타일(Identity)을 시각화.

행동: [3분 만에 내 Work-TI 알아보기] 버튼 클릭 ➔ 24개 딜레마 질문 및 3개 소통 문화 질문 응답.

구성요소:

메인 카피: "일하는 데 정답은 없지만, 나에게 맞는 방식은 있습니다."

서브 카피: "3분 만에 알아보는 나의 Work-TI | Work with Identity"

CTA 버튼: [3분 만에 내 Work-TI 알아보기]

카드형 퀴즈 UI, Progress Bar.

화면 2: 대시보드 (매칭 리스트 & 커스텀 채용 필터)

가치: "나에게 딱 맞는 회사 찾기, Work with Identity." 내 성향을 확인하고 원하는 채용 전형만 골라보기.

행동: 상단에서 내 WORK-TI REPORT 카드를 확인 후, 원하는 채용 전형 필터 체크.

화면 3: AI 기반 매칭 리포트 및 공고 상세

가치: 구직자에게 명확한 채용 프로세스를 안내하고 직관적인 지원 유도.

행동: AI가 요약한 핏 리포트와 해당 기업의 채용 프로세스 태그를 확인하고 지원.

구성요소: * 해당 공고의 상세 내용 및 채용 전형 프로세스 안내 태그(예: 서류 ➔ 포트폴리오 심사 ➔ 1차 실무면접)

AI 매칭 리포트 영역: 헤더에 Work Identity Match 92% 수치를 큼직하게 띄우고, 왜 이 수치가 나왔는지(어떤 성향이 맞는지) AI가 짧게 설명.

버튼: 익숙하고 명확한 [지원하기] 버튼 (기업의 부담을 최소화).
